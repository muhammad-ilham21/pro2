# Project 2 - Modal Demo

A simple project showcasing a clean and responsive modal popup built with **HTML, CSS, and JavaScript**.  
The modal includes smooth open/close animations and adapts well to mobile screens.

## 🚀 Live Demo
Check out the project here: [Live Demo](https://muhammad-ilham21.github.io/pro2/)

## 📂 Project Structure
- `index.html` → Main HTML file
- `style.css` → Styling for modal and responsiveness
- `script.js` → JavaScript logic for opening/closing modal

## ✨ Features
- Clean UI with modern design
- Smooth open/close animations
- Responsive layout for mobile devices
- Easy to customize and extend
